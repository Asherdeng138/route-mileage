# 里程记录（安卓）

开私家车出差时，用手机 GPS 自动记录每一趟的路线和里程，每月一键生成公司格式的 **Word + Excel 报销文件**。

- 锁屏、切到导航 App 时照样记录（安卓前台定位服务）
- 按实际行驶路线算里程；隧道、乡村没信号的路段，可以按 Google 驾车路线补算
- 公司费率 £0.45 / £0.25（每个累计年度前 10,000 英里 / 之后），自动处理跨档
- 报销后归档，60 天后自动清理，本年累计里程不受影响
- Google 接口可选：不配置也能用；配置后支持附近地点识别和信号中断补算（需要哪些 API 见下文）
- 数据只存在手机里，不需要注册账号

> 当前版本：**1.7.2**（2026-10）

## 下载安装

1. 打开 **[Releases 页面](https://github.com/Asherdeng138/route-mileage/releases/latest)**，下载 APK：
   | 文件 | 适用 |
   |---|---|
   | `RouteMileage-1.7.2-arm64.apk`（约 50 MB） | **推荐**，近几年的安卓手机都用这个 |
   | `RouteMileage-1.7.2-universal.apk`（约 120 MB） | 很旧的 32 位手机，或上面那个装不上时 |
2. 在手机上点开下载好的 APK，按提示允许「安装未知来源应用」。
3. 以后有新版本，直接下载新 APK 覆盖安装，**数据会保留**。

**提示「与已安装应用签名不同」**：说明手机上装的是 1.1.1 或更早的测试版。先在旧版里「设置 → 导出备份」，卸载旧版，安装新版，再「设置 → 从备份恢复」。从 1.2.0 起所有版本签名相同，可以直接覆盖安装。

## 第一次使用

1. **权限**：开始记录时按提示允许定位。建议把定位改成「**始终允许**」并打开「**使用确切位置**」，允许通知。
2. **电池设置**（很重要，否则后台可能被系统杀掉）：系统设置 → 应用 → 里程记录 → 电池 →「不受限制」。小米 / 红米还要打开「自启动」。App 内「后台记录说明」里有各品牌的设置方法。
3. **常用地点**：在「设置 → 常用地点」添加家、公司、常去的门店。起终点在这些地点附近时会自动显示名称。
4. **往月里程**：如果本税年（4 月 6 日起）在使用 App 之前已经开过车，在「设置 → 往月里程」填入各月合计，本年累计和 10,000 英里分档才准确。

## 日常怎么用

| 步骤 | 操作 |
|---|---|
| 出发 | 首页点「开始记录行程」，然后锁屏或打开导航都可以 |
| 到达 | 回到 App 点红色「结束记录」；忘了也没关系，停车 20 分钟会自动结束并保存（可在设置里改） |
| 补全 | 结束后确认起点、终点、途经地点；也可以在地图上拖动选点 |
| 忘记开记录 | 「手动补录」：填日期、起终点和单程里程，可选往返 |
| 月底报销 | 「报表」→ 选月份 → 修正标红的问题 →「生成 Word + Excel」→ 分享到邮箱或保存到文件夹 |
| 公司已付款 | 首页或报表顶部的「等待公司报销」里点「已报销」，报表和行程移到底部的「归档」 |

**归档与自动清理**：底部有单独的「**归档**」标签。报表里只留还没报销的；确认已报销后，报表和行程都移到「归档」，按月显示，可以重新分享 Word / Excel、撤销已报销或删除。在「归档」保留 30 天后自动移到「最近删除」（还能恢复），再过 30 天永久删除。永久删除后只保留日期和里程，保证本年累计不变。

## 地图和 Google（可选）

**不配置 Google 也能完整使用**：公开下载的安装包不带任何 Google Key，地图用 OpenStreetMap，地址用手机自带的地址解析，Word 里的路线图也用 OpenStreetMap，全部免费。

配置了自己的 Google Maps Platform Key 后，可以多用下面这些功能：

| Google 接口（在 Google Cloud 里启用的名字） | App 里的功能 | 计费 SKU | Google 每月免费 | App 上限 | 必需吗 |
|---|---|---|---|---|---|
| **Places API (New)** | 起点、终点附近的门店 / 公司名称自动识别；地图选点时显示附近地点 | Nearby Search **Pro** | 5,000 次 | 3,500 次（可调低） | 可选 |
| **Routes API** | 信号中断补算：隧道、乡村没信号的路段按 Google 驾车路线补上里程 | Compute Routes **Essentials** | 10,000 次 | 7,000 次 | 可选 |
| **Maps SDK for Android** | App 内显示 Google 原生地图（记录页、行程详情） | Mobile Native Dynamic Maps | 不限次数，免费 | 不计数 | 只有自己构建时用 |

- 不需要的接口：Geocoding API、Directions API（旧版）、Maps Static API、Places API（旧版）都**不用启用**。地址解析用手机系统自带的，免费。
- **公开安装包**：在「设置 → Google 地点」粘贴 Key，就能用 **Places API (New)** 和 **Routes API**。Google 原生地图需要构建时把 Key 打包进安装包，公开安装包不提供，App 内地图仍是 OpenStreetMap。
- **自己构建**（见下面「开发者」）：把 Key 放在 `.secrets/google-api-key.txt` 再运行 `npm run build:apk`，三个接口都能用。

### 申请 Key（约 10 分钟）

1. 打开 [Google Cloud Console](https://console.cloud.google.com/)，新建项目，绑定结算账户（Google 要求绑卡，但在免费额度内不收费）。
2. 「API 和服务 → 库」里启用：**Places API (New)**、**Routes API**；自己构建的话再启用 **Maps SDK for Android**。
3. 「凭据 → 创建凭据 → API 密钥」，在「API 限制」里**只勾选**上面启用的这几项。
4. 建议在各接口的「配额」里设置每日上限，作为 App 之外的第二道保险：Places API (New) 的 `SearchNearbyRequest per day` 设为 50 左右，Routes API 的 `ComputeRoutes requests per day` 设为 100 左右。再在「结算 → 预算和提醒」设一个小额预算提醒。
5. 把 Key 粘贴到 App「设置 → Google 地点」，点「测试连接」。

App 里「设置 → Google 地点」也有同样的分步说明和本月用量。

### 费用控制

- 每个收费接口**单独计数**，App 上限 = Google 每月免费额度 × 70%，到上限后本月自动改用免费来源（OpenStreetMap / 按直线计算），下个月自动恢复。计费月按太平洋时间，和 Google 一致。
- **只有调用成功才计数**：没网、超时、Key 错误、接口没启用都不算。
- 普通用量：每趟行程大约 2 次附近地点查询（起终点在常用地点附近时不查），只有出现信号中断的行程才会调用 Routes API。一个人每月远远用不到免费额度。
- Key 只存在手机的加密存储里，不上传，也不进备份文件。
- 如果给 Maps SDK 用的 Key 加「Android 应用」限制，包名是 `com.mia.routemileage`，SHA-1 填你自己签名密钥的指纹。Places / Routes 是 App 直接发出的网络请求，「Android 应用」限制对它们不一定生效，所以主要靠上面的「API 限制 + 每日配额」。

**信号中断补算怎么算**：两点之间断开 ≥ 60 秒且相距 ≥ 300 米时，向 Google 要驾车路线（含备选路线），选「预计用时最接近实际断开时间」的那条补上里程，地图上画虚线，行程详情里可以撤销。

## 省电

行驶中约每 8 秒一个点；停车 2 分钟后自动切到低功耗定位，开动后恢复；后台时系统每 60 秒批量交付位置；界面在后台不刷新。详见 App 内「后台记录与省电说明」。

## 数据与隐私

- 行程、轨迹、地点都只保存在手机本地，不需要账号，不上传到任何服务器。
- 显示地图时会向 OpenStreetMap（或你自己配置的 Google）请求所在区域的地图 / 路线，**不会上传轨迹**。
- 建议每月「设置 → 导出备份」一次，把 JSON 文件存到网盘或发到邮箱；换手机时「从备份恢复」。

## 常见问题

- **路线变成了直线**：中间一段时间没有定位。常见原因：定位权限只给了「大致位置」、电池设置限制了后台、隧道 / 地下停车场。配置了 Google Key 时可以自动补算。
- **通知栏没有「正在记录行程」**：后台记录被系统停止了，回到 App 点「继续记录」，并检查上面的电池设置。
- **金额和 Excel 差 1 便士**：和公司样板一样，单行金额显示四舍五入，合计按精确值计算后只舍入一次。

## 开发者

技术栈：Expo SDK 58 · React Native 0.88 · Expo Router · expo-sqlite · expo-location。设计说明、计算规则、测试和构建步骤见 **[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)**。

```bash
npm install
npm test                    # 单元 / 集成测试
npm run build:apk           # 本机构建（使用 .secrets 里的签名密钥和 Google Key）
npm run build:apk:public    # 公开发布用：不打包任何 Key，并检查 APK 里确实没有 Key
```

`.secrets/`（签名密钥、API Key）和公司内部的 `example/` 样板不在仓库里。没有签名密钥时，请在 `plugins/withReleaseSigning.js` 说明的位置放入你自己的密钥。
